# Projeto de Vida — Rerisson, Carlos e Ramon

Site escolar que apresenta os objetivos profissionais de três estudantes:
- **Rerisson:** Operador de Máquinas
- **Carlos:** Policial
- **Ramon:** Médico

## Arquivos
- `index.html` — estrutura do site
- `css/style.css` — aparência e responsividade
- `js/script.js` — menu mobile e ano automático

## Como abrir no VS Code
1. Extraia o arquivo ZIP.
2. Abra a pasta `Projeto_de_Vida_1Rerisson_Carlos_Ramon` no Visual Studio Code.
3. Abra o arquivo `index.html`.
4. Clique com o botão direito e escolha **Open with Live Server** (se a extensão estiver instalada). Também é possível abrir o `index.html` diretamente no navegador.

O site é responsivo e funciona sem banco de dados.
